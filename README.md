# KRS-3204 ICS / M5Stack Core2

Core2からICS3.5の位置指令を送るPlatformIOプロジェクトです。専用ICS変換基板は使いませんが、**GPIOとサーボ信号線の裸配線での直結はできません**。ICSは5V TTL、ESP32は3.3V系のため、以下のディスクリート部品によるレベル変換回路を使います。ソフトウェアだけでは過電圧を防げません。

## 配線（サーボ1台、115200bpsで開始）

必要部品：BSS138 NチャネルMOSFET 1個、2.2kΩ抵抗2本、配線、サーボ用外部電源。
MOSFETのG/S/Dの端子配置は使用する部品のデータシートで確認してください。

```text
Core2 3.3V ----+----[2.2kΩ]----+   LV（3.3V信号）
              |              |
              G              +---- GPIO13 (UART RX)
           BSS138            +---- GPIO14 (UART TX / open drain)
              S--------------+
              D------------------- KRS-3204 信号
              |
Core2 5V -----[2.2kΩ]         HV（5V信号）

外部電源 +6～7.4V ----------------- KRS-3204 Vcc
外部電源 GND ---- Core2 GND -------- KRS-3204 GND
```

- GateはCore2の3.3V、SourceはGPIO13/14共通ノード、Drainはサーボ信号です。GとSを短絡しないでください。
- GPIO13/14・3.3V・5V・GNDはM-BUSから取り出せます。PORT-Cを備える拡張底面ではGPIO13/14を利用できますが、PORT-C単独では3.3Vを取り出せません。
- 5Vは信号のプルアップ用です。6～7.4Vのサーボ電源とは接続しません。USB給電でCore2側の5Vを確保してください。
- サーボはCore2の5V/3.3V端子から給電せず、負荷に見合う電流容量の外部電源を使用します。電源のマイナスとCore2のGNDを共通にします。
- サーボの信号/Vcc/GNDは本体表示・取扱説明書で確認してください。サーボ電源をCore2の端子に入れないでください。
- GPIO14はUART初期化後にオープンドレインに設定します。送信HIGH時は出力を開放するため、サーボの応答と衝突しません。GPIO13で送信エコーと応答を受信します。ENピンは不要です。

この回路はMOSFETの双方向レベル変換原理をICSの半二重通信に応用した構成で、メーカーのICS専用推奨回路そのものではありません。実機での波形・動作確認は未実施です。まず短い配線・1台・115200bpsで使用し、高速化や複数台接続は波形を確認してから行ってください。

## ビルドと使用手順

```powershell
pio run
pio run -t upload
pio device monitor
```

`pio`がPATHにない場合はPlatformIO IDEのBuild/Upload/Monitor、または `& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run` を使用できます。

1. 電源を切って配線します。初回は機構の干渉がない状態で確認します。
2. Core2をUSBで起動します。起動時にサーボへコマンドは送信しません。
3. サーボ用電源を入れ、1秒以上待ちます。ICS3.5はサーボ電源投入後に信号HIGHを500ms以上維持してシリアルモードに入ります。
4. 中央Bボタン（FREE）で通信確認します。成功すると `FREE confirmed` と現在位置を表示します。FREEは保持トルクを解除するので、荷重のある機構は支えてください。
5. A/Cボタンで位置を変更します。停止時はサーボ電源を先に切ります。

| 操作 | 動作 |
| --- | --- |
| 左A / USB `j` | 目標値を100減らす |
| 中央B / USB `f` | トルク解除・現在位置取得 |
| 右C / USB `k` | 目標値を100増やす |
| USB `c` | 中央位置7500を指令 |

USBモニターは115200bpsの通常設定（8N1）、サーボ用UART2は115200bps **8E1**（偶数パリティ）です。

## 設定と通信動作

`src/main.cpp` 冒頭の `Config` でID、ピン、通信速度、位置制限を変更できます。初期設定はID 0 / 115200bpsです。サーボに保存済みの設定と一致させてください。このプログラムはサーボのID・通信速度・EEPROM設定を変更しません。

デモの目標範囲は7000～8000、中央7500、1操作100です。ICSプロトコルの指定範囲3500～11500より狭く制限していますが、実機の機械的な可動範囲を保証するものではありません。起動時の目標値は7500です。FREE成功後は読み取った現在位置を7000～8000に制限して次の目標値に使います。現在位置が範囲外の場合、最初の移動は100より大きくなります。

位置指令は `[0x80 | ID, position >> 7, position & 0x7f]` の3バイトです。位置0はFREEです。配線による送信エコー3バイトとサーボ応答3バイトを区別し、エコーの一致・応答ID・データの上位ビットを検証します。画面のReplyはコマンド応答時の位置で、目標到達確認や継続監視ではありません。

タイムアウトは30msです。通信失敗時は画面に原因を表示し、自動で位置指令を再送しません。応答がなくても送信済みの指令が実行されている可能性があり、エラー表示は停止やトルク解除の保証ではありません。

## 切り分けと実機確認

- `No echo`：GPIO13/14共通接続、MOSFET端子、プルアップ、GNDを確認。
- `No reply`：サーボ電源、ID、通信速度、シリアルモードへの起動順を確認。ICS3.5のサーボをPWM信号では制御しません。
- `Echo mismatch` / `Invalid ICS reply`：電圧、配線長、共通GND、他の送信機の接続を確認。
- `Bus stuck LOW`：短絡、MOSFETの向き、プルアップを確認。
- サーボ信号を外して操作すると成功せず `No reply` になることを確認。
- 接続後にFREE、中央、±100の順で確認し、実際の位置変化と応答を照合。
- オシロスコープがあれば、LV側が約3.3V/HV側が約5V、アイドルHIGH、8E1、エコー3バイト＋応答3バイトを確認。
